# 90 秒 demo 腳本

請先用 Chrome 開啟工具，允許攝影機與麥克風，確認中文口令可正常辨識。可使用內建範例 PPTX 或自己的簡報。

| 時間 | 操作 | 觀眾看見什麼 |
| --- | --- | --- |
| 0–15 秒 | 上傳一份 PPTX | 真實轉換與五頁縮圖 |
| 15–30 秒 | 開啟攝影機，張掌右揮一次 | 手部骨架、手勢狀態、只換一頁 |
| 30–45 秒 | 說「上一頁」 | 語音辨識文字，回到上一頁 |
| 45–60 秒 | 只伸食指，慢慢從左移到右 | 投影片上的紅色亮點移動，頁碼不變 |
| 60–75 秒 | 張掌停住，再說「簡報，暫停」 | 停住不誤觸；語音可暫停手勢 |
| 75–90 秒 | 說「簡報，繼續」，再右揮 | 恢復手勢並切到下一頁 |

可先錄工作區畫面，讓觀眾同時看見攝影機和辨識結果，再展示全螢幕。

口令測試欄與滑鼠指示模式適合功能操作錄影，但若使用這兩個備援功能，影片應明確標示「文字口令測試／滑鼠指示」，不能當作真人手勢、麥克風辨識成功的證據。
